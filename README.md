# SPOT UPI - Custom Theme & Wallpaper

This browser extension version 4.0 is specifically designed to modify and beautify the interface of the Integrated Online Learning System (SPOT) of Universitas Pendidikan Indonesia on the `spot.upi.edu` website. This extension transforms the default look into a modern UI that is more comfortable for daily activities.

## Key Features

* **Custom Wallpaper**: Provides a dedicated button allowing users to upload their own custom background image directly into the SPOT UPI web page.


* **Visual Theme Options (Modal UI)**: Features an interactive overlay menu to choose from five different visual styles, including Light Mode, Dark Mode, Warm Earth, Classic Slate, and Cyberpunk (Neon Red & Blue).


* **Modern Tables and Components**: Changes the standard table design to a modern table style with rounded corners in most themes, and a sharp corner effect with neon lighting in the Cyberpunk theme.


* **Course Detail Page Redesign**: This extension automatically detects default elements such as blue banners, panels, and "Waktu Akses" chips, and overhauls their colors to blend perfectly with the overall active theme.


* **Menu Visual Bug Fixes**: Removes block-forming elements or black boxes (*pseudo-elements*) on the left sidebar menu, making the menu appearance and shadows much cleaner.
